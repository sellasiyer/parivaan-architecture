Serial hot path

box width ∝ time · colour = cost · hover a stage

Every stage between a FEC arriving in the mev tile and a signed transaction leaving over QUIC. Particles dwell in proportion to cost, so the parse stage visibly congests — it owns 45% of the budget on its own.

What runs in parallel

single FEC · microseconds · playhead sweeps the 111 µs window

Only the main thread is serial. The mevin ingest tile, the DFS cycle worker and the Phase 3b BPF shadow executor all overlap it. BPF runs 70–300 µs and commits about 15% of executed transactions — it corrects state after the fire rather than gating it, which is why it sits off the critical path entirely.

System topology

minimal observer build · replay, repair, tower, txsend, gossip removed

Firedancer is reduced to a network stack and a frozen account database. The mev tile absorbs the responsibilities the removed tiles used to hold: fd_store eviction, cold-path bootstrap, and peer plus leader discovery through an in-tile HTTPS worker that replaced gossip entirely.

Where it was actually lost

same scale · microseconds

The entire code path is a rounding error against the thing that decided the outcome. A Solana slot is 400 ms. Arriving one slot late means the spread is already gone, no matter how fast the engine was.

The engine was not the constraint. On-chain forensics across the landed signatures showed pool state on par with mainnet — the same shred stream reaches the engine and the leader at the same time — and every swap instruction reaching the DEX correctly. All five errored Custom:3005, DEX slippage, because the price had already moved.

Competitors landed one to two slots earlier while paying a quarter of the priority fee. Stake-weighted queue position at the leader's QUIC endpoint is worth more than fee bidding at unstaked rates. That is a submission-side gap, not an ingestion-side one, and no amount of microsecond optimisation above it changes the result.
